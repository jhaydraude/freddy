# NightManager Shared

Shared TypeScript types and utilities used across NightManager packages.

## Purpose

This package contains:
- Common TypeScript interfaces and types
- Shared utility functions
- Constants and enums

## Usage

Import shared types in other packages:

```typescript
import { IGlucoseResult, IIOBResult } from '@nightmanager/shared';
```

## Development

Build the package:
```bash
npm run build
```

This will compile TypeScript to the `dist/` directory with type definitions.
