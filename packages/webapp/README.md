# NightManager WebApp

Web application interface for NightManager, powered by the MCP server.

## Status

🚧 **Under Development** - This package is a placeholder for the upcoming web interface.

## Planned Features

- Interactive diabetes management dashboard
- Real-time glucose monitoring
- IOB/COB visualization
- Profile analysis and recommendations
- Treatment logging
- AI-powered insights and explanations

## Architecture

This webapp will communicate with the NightManager MCP server to access all diabetes management data and tools.
